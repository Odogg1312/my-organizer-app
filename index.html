Welcome to My Organizer

Sign in or create an account to see your reminders, notes, and settings on your devices.

One-time account setup is needed:
  1. Create a Supabase project, enable email/password sign-in, and add this site's address to the allowed redirect URLs.
  2. Open the Supabase SQL Editor, paste in the database setup file, and run it.
  3. In VS Code, add your Supabase Project URL and publishable key to supabase-config.js.

If email confirmation is on, new users must confirm their email before signing in.

Only use the publishable/anon key here. Never put a service-role or secret key in this website.
